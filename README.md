# PaginaReceita

Página web desenvolvida para exibição de receitas culinárias utilizando **HTML** e **CSS**, focada na estruturação de conteúdo semântico, organização de listas de ingredientes e instruções passo a passo.

## Funcionalidades

- **Apresentação da Receita:** Exibição organizada de receitas culinárias com estrutura visual limpa.
- **Lista de Ingredientes:** Organização clara dos ingredientes necessários para o preparo.
- **Instruções Passo a Passo:** Sequência estruturada de etapas para facilitar a leitura e acompanhamento.
- **Estrutura Semântica e Visual:** Marcação em `index.html`, estilos definidos em `style.css` e recursos visuais armazenados na pasta `assets`.

## Tecnologias Utilizadas

- **Marcação:** HTML5 (`index.html`)
- **Estilo:** CSS3 (`style.css`)
- **Recursos Visuais:** Pasta `assets`
